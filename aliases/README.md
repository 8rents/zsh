# ZSH Aliases 

> *Folder to hold all of your aliases*

---

## The `aliases/aliases.zsh` file

The `aliases.zsh` is directly included into the `.zshrc` file. All other alias files are included into the `aliases.zsh` file so as not to pollute the `.zshrc`.

You can use the `aliases.zsh` by either being lazy and entering aliases directly into the file, or you can create a dedicated file and load it into the `aliases.zsh` file. Either way works, one way is quick and easy, the other way is better for long term configuration. Nothing is preventing you from using both at the same time.
