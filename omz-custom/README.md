# OMZ Custom

> *The custom directory for oh my zsh plugins and themes*

`~/dotfiles/shells/zsh/omz-custom`

---

Any files with a .zsh extension will be loaded by oh my zsh

## Directories 

- **plugins** - The directory to place alias files. they must have the extension `.plugin.zsh`
- **themes** - The directory for custom themes. they must havr the extension `theme.zsh`
