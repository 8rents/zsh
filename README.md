# Oh my Brent's on H!    
*Brent's "Oh my ZSH" theme*

**Install Location:** `~/settings/shells/zsh/oh-my-brent-on-h/`

> *Brent's old "Oh my zsh" theme and aliases. I've since migrated away from using OMZ in favor of a more custom and grass roots solution.*

---

## Installation

1. Have Oh my zsh installed
2. Clone `oh-my-brent-on-h` into the main zsh folder
